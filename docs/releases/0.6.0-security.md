Applicability: the Tinypool and mocker issues need an attacker to control worker options or mock registrations
in the test process; minimatch needs attacker-controlled glob patterns. None of these run in the published
library, which has no runtime dependencies.

## Fix

- `vitest` ^3.2 → ^5.0.5 (no Tinypool; patched mocker). Config and all 707 tests unchanged.
- `eslint` ^9.39 → ^10.14 and `@eslint/js` ^10 (ESLint 9 is end of life), `typescript-eslint` ^8.72.
- Root `overrides`: `minimatch` ^11.0.3 for `eslint`, `@eslint/config-array` and
  `@typescript-eslint/typescript-estree` (they use the same named API); `eslint-plugin-jsx-a11y` accepts
  ESLint 10 (its peer range stops at 9; its flat config and rules run unchanged on 10, and `npm run lint` passes).
- Lockfile regenerated so every transitive dev package takes its latest in-range patch. Playwright stays on 1.56.0
  (the CI image pin depends on it).
- One new ESLint 10 rule finding fixed (`no-useless-assignment` in `SortableList.tsx`, no behavior change).
