# @onesmall/ui 0.6.0 release notes (draft for the GitHub release)

A hardening release. Nothing was removed and no public API changed incompatibly, so upgrading from 0.5.0 is
`npm install @onesmall/ui@0.6.0`.

## Highlights

- **Short viewports:** menus, popovers, comboboxes, tag inputs, time pickers and date pickers stay on screen
  in landscape phones, 320px-tall windows and when zoomed in. Content that doesn't fit scrolls inside the
  panel. Custom panels can use the new `--os-floating-available-height` variable.
- **React 18 server rendering:** components no longer print `useLayoutEffect` warnings during SSR with React 18.
- **TimePicker:** the list matches the field's width instead of the whole viewport.
- **Verified compatibility:** every CI run installs the packed package into clean React 18 and React 19 apps
  on Node 18, 20, 22 and 24 (ESM, CommonJS, strict TypeScript, SSR, hydration, CSS, SCSS, tree shaking).
- **Security:** development tooling was updated (Vitest 5, ESLint 10), clearing two critical and most
  moderate advisories. The published package has no runtime dependencies, and its production audit is clean.
- **Docs:** a complete component inventory, a compatibility table, upgrade, rollback and uninstall
  instructions, and accessibility claims that match what is measured.

## Notes

- `computePosition` results now include `availableHeight` and `availableWidth`. Code that only reads the
  result is unaffected.
- Contributors need Node 22.13+ to work on the repository. Apps using the package still need only Node 18.18+.
- Rating half-step targets are 24×44px (WCAG 2.5.8 AA). Use whole steps where 44px targets matter.
