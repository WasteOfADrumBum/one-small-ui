# @onesmall/ui 0.6.0: release scope and acceptance criteria

Status: **frozen 2026-11-01** by the builder (Claude Code) for owner review. Release approval belongs to Joshua Small.

## How this scope was chosen

The owner brief and the Engineering Hub name 0.6.0 as the next release and mention "page blocks" (Phase 5).
No page-block specification exists in this repository, its issues, the project files or the Engineering Hub
(the Hub records this as blocker `scope-document-missing`). Following the brief ("choose the smallest coherent,
backward-compatible release based on documented intent"), 0.6.0 is a **hardening release** of the 0.5.0
library. Page blocks are deferred until the owner writes their specification; no page-block API ships in 0.6.0.

## Already implemented (0.5.0 baseline, published to npm 2026-10-16)

All components, hooks, icons, tokens, the `dom` layer and docs listed in `CHANGELOG.md` up to 0.5.0.

## Explicitly deferred

- **Page blocks (Phase 5)**: needs an owner-written spec (which blocks, API shape, responsive rules). Unresolved
  product decision, not authorized by this scope.
- ChipInput removal (planned for 1.0.0).
- Any visual redesign.

## Compatibility requirements

- No breaking public API change. New props are optional with defaults that keep 0.5.0 output.
- Peer dependencies stay `react` / `react-dom` `^18 || ^19`.
- ESM + CJS entrypoints, bundled `.d.ts` / `.d.cts`, `./icons`, `./dom`, CSS, SCSS and `tokens.json` exports unchanged.

## Accessibility criteria

- `npm run test:a11y` (axe WCAG 2.x A/AA/AAA + best practice, light and dark) reports 0 violations.
- jest-axe component tests pass; `npm run test:layout` passes, including new short-viewport checks.
- Claims are WCAG 2.2 AA minimum; AAA only where measured (token contrast is checked at 7:1).
- Manual screen-reader testing is not performed by the builder and stays an owner/verifier task.

## Packaging and documentation requirements

- Version 0.6.0 in the root, library and docs packages; CHANGELOG `[0.6.0]` entry.
- Release notes, upgrade/rollback/uninstall instructions, checksum of the packed tarball.
- Publication, tags and GitHub release objects are owner-only.
