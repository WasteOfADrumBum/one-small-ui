# 0.6.1 release scope

Patch release to publish the existing 0.6.0 library with npm provenance through GitHub Actions trusted publishing. Component APIs and behavior are unchanged. The 0.6.0 package remains published without npm provenance; this release does not alter its history.

Before publishing, confirm the CI checks pass for the merged release commit. In npm package settings, add a GitHub Actions trusted publisher with owner `WasteOfADrumBum`, repository `one-small-ui`, workflow filename `publish.yml`, no environment, and allow `npm publish`. Do this shortly before publishing: new trusted publishers expire if unused after two days.

Run the `Publish package` workflow manually on `main` after the release PR is merged. The workflow checks version 0.6.1, runs the project checks, builds and smoke-tests the tarball, then publishes that same tarball with npm provenance. It needs no npm publishing token. Verify the published version and its provenance on npm after the run. The workflow does not create a Git tag or GitHub release; handle those separately after publication.

Until the workflow runs successfully, 0.6.1 is a release candidate and has not been published or attested.
